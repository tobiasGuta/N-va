# Nova v0.5.4 — First stable milestone

Our first Fedora-tested public release of **Nova**, a lightweight Dynamic Island-inspired GNOME Shell extension with no AI, Electron, or background daemon.

## Highlights

- **Clock-first experience:** local time and calendar by default, automatically switching to music when an MPRIS-compatible player is actively playing
- **Media controls:** album artwork, play/pause, previous/next and a small animated playback indicator
- **Floating top bar:** transparent GNOME panel background that retains system controls
- **Live activities:** timer presets, ordinary notification previews, download activity/completion, volume and brightness indicators, GNOME built-in screen recording status
- **Native preferences:** pill widths, color accent, animation speed and individual activity toggles

## Install

**Requirements:** GNOME Shell **49–51** on a Linux desktop such as Fedora Workstation; the extension has been exercised on Fedora but has not been runtime-verified on every supported GNOME version.

**From the release ZIP (recommended for a versioned install):**

1. Download `Nova-v0.5.4-GNOME.zip` from the Assets section.
2. Run `gnome-extensions install --force Nova-v0.5.4-GNOME.zip`.
3. Log out and back in on Wayland.
4. Run `gnome-extensions enable nova@tobiasguta.github.io`.

**Or install from source:**

```bash
git clone https://github.com/tobiasGuta/N-va.git
cd N-va
bash install.sh
```

After logging out and back in, enable the same extension UUID.

Open settings with:

```bash
gnome-extensions prefs nova@tobiasguta.github.io
```

## Notes and limitations

- The GNOME panel remains functional; only its appearance changes. Blur my Shell may need its panel-blur effect disabled.
- Notifications are not deleted; Nova can replace ordinary banners while GNOME keeps critical alerts. You can change this in preferences.
- Download tracking is **best effort** for the configured XDG Downloads folder; exact browser percentages are not available. Direct-to-final small downloads are briefly settled before completion is shown.
- Screen-recording status is for GNOME's built-in recorder, not every third-party app.
- Remote album art is fetched only while media is playing, over restricted HTTPS requests; see the README's privacy section.
- **Licensing has not been selected yet.** This public release does not imply an open-source redistribution license.
