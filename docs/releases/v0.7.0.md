# Nova v0.7.0 — Richer notifications, without losing GNOME

Nova v0.7.0 brings more useful GNOME notification previews to the lightweight Dynamic Island experience.

## What's new

- **Fuller previews:** Read the sender app/source, title, and message body separately in a taller island card.
- **Application icons:** When the GNOME notification source provides a compatible GIcon, Nova shows it; otherwise it uses a safe generic icon.
- **Notification queue:** Up to six additional alerts wait in FIFO order instead of overwriting the active preview. A `+N` badge shows how many are waiting.
- **Smart fallback:** If the queue is full, Nova is hidden, or the session is locked, it doesn't acknowledge or suppress the incoming GNOME banner. Critical alerts remain native, and GNOME's notification history remains available.
- **Bounded plain text:** Notification strings have control characters removed and size limits to avoid clutter; Nova doesn't render incoming text as markup.
- **Testing and documentation:** More unit/static checks, GNOME schema and ZIP packaging validation, and a [Fedora notification test guide](../NOTIFICATIONS.md).

Everything from v0.6 remains: MPRIS music, themes, clock/calendar, timers, download previews, volume/brightness OSD, optional local developer activity API, and settings.

## Installation

Get `Nova-v0.7.0-GNOME.zip` from this release's **Assets** and install it from the downloaded file's directory:

```bash
gnome-extensions install --force Nova-v0.7.0-GNOME.zip
```

Log out and back in on GNOME Wayland, then enable the extension:

```bash
gnome-extensions enable nova@tobiasguta.github.io
gnome-extensions info nova@tobiasguta.github.io
```

The expected extension metadata version is **11**.

To update an existing source checkout instead:

```bash
cd ~/N-va
git checkout main
git pull origin main
bash install.sh
```

Log out and back in afterward. Existing preferences should be preserved.

## Validation and limitations

The project maintainer reported successful Fedora testing with notifications from multiple real desktop apps. Automated syntax/logic tests, GSettings validation, and installable ZIP checks also passed.

**Not yet independently verified:** all GNOME 49–51 environments, critical/overflow behavior in every setup, lock-screen scenarios, accessibility scaling, and long-running CPU or memory benchmarks. GNOME-specific notifications and in-app proprietary popups are not necessarily accessible through Shell's notification sources. Icon availability depends on the app. Nova doesn't store a second notification history.

## Privacy and licensing

Nova listens to the same GNOME Shell notification sources used for desktop notifications and renders text in the island. It does not upload, persist, or create a separate notification database.

The repository owner has not yet selected a software license; the public repository and binary release do not themselves grant additional reuse or redistribution rights.
