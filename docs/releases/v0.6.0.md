# Nova v0.6.0 — More personal. More Linux-native.

Nova v0.6.0 is the next stable milestone for the lightweight GNOME Shell Dynamic Island extension, building on v0.5.4.

## What's new

- **Five capsule palettes:** Custom (your saved accent), Mint, Ocean, Violet and Sunset, selectable live in Preferences.
- **Keyboard interaction:** Optional `Super + Shift + N` or `Super + Alt + N` shortcut for opening/closing Nova, disabled by default to avoid conflicts.
- **Resource-conscious UI:** Fewer redundant actor updates for static previews, visualizer cleanup while hidden, and an option to disable the decorative music bars.
- **Linux developer activity API:** Optional local session D-Bus method to display a short status card from your build tools, scripts, or terminal. Disabled by default, with bounded text and durations.
- **Project quality:** New automated tests, package verification, documentation, contribution templates, and development roadmap.

## Preserved functionality

Music and album art via MPRIS, calendar and clock, transparent GNOME panel, native notifications and optional banner replacement, timer, volume/brightness OSD, built-in GNOME screen-recording indicator, and filesystem-driven download activity and completion.

## Install

**GNOME Shell 49–51** is the declared compatibility range. Fedora GNOME has been tested by the project maintainer; not all Shell versions or custom themes have been tested.

Download `Nova-v0.6.0-GNOME.zip` from this GitHub release's **Assets**, then from its download directory:

```bash
gnome-extensions install --force Nova-v0.6.0-GNOME.zip
```

Log out and back in on a Wayland session and run:

```bash
gnome-extensions enable nova@tobiasguta.github.io
gnome-extensions prefs nova@tobiasguta.github.io
```

To update a source checkout instead:

```bash
cd ~/N-va
git checkout main
git pull origin main
bash install.sh
```

Log out and back in after reinstalling. Existing saved preferences persist, while the new theme/shortcut/developer API have safe defaults.

## Fedora verification

The maintainer reported successful real GNOME desktop checks of the new theme presets, shortcuts and developer API, and regressions for music, downloads, notification behavior, and enable/disable. GitHub Actions also validates JavaScript, GSettings schemas and the installable ZIP. This does **not** establish benchmarked CPU/memory performance or compatibility with every GNOME 49–51 setup.

## Privacy and limitations

The developer API is opt-in. Processes on the same D-Bus session can submit bounded display text when enabled; it is not an authentication boundary and does not execute commands, read arbitrary files or start a daemon. Download percentages are unavailable without browser-specific integration, and GNOME's built-in recorder detection does not imply third-party PipeWire recording support.
